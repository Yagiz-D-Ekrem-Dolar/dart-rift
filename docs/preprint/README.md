# DART-RIFT pilot-results preprint

[Read the four-page PDF](../../output/pdf/DART-RIFT_Pilot_Results_2026-10-10.pdf).

This preprint reports five completed, validity-checked simulations: a three-point cohesion sweep, one matrix-tension toggle, and one 25 m impact-site offset. Its three vector figures are generated from the checked pilot values and the registered 96-point coarse / 12-point fine design. The paper distinguishes these scene-conditioned findings from a production posterior or a sealed numerical Hera forecast; neither is reported here. Two DOI records are planned, but neither has been assigned or deposited.
