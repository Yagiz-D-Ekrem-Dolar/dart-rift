\begin{abstract}
This document fixes, in advance of the data, every rule by which we will
judge a Bayesian inference of Dimorphos's interior parameters
$\theta=(\alpha_b,Y_0,f)$ from the DART momentum enhancement. No result is
reported. What is reported is the model, the experimental design, the
measured model-discrepancy budget, and five decision gates, two of which
stop publication outright. The accompanying repository carries the
protocols, the code and the tests that pin these choices.
\end{abstract}
