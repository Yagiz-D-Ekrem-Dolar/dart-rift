# Arşiv — tarihsel çalışma belgeleri

Buradaki belgeler **güncel değildir ve güncellenmeyecektir.** Yazıldıkları
tarihte neyin bilindiğini gösterirler; bugünkü durumu anlatmazlar.

*yanlış çıkan bir iddia silinmez, notla düzeltilir.* Bir araştırma
deposunun değeri, nerede yanıldığının izlenebilir olmasındadır.
